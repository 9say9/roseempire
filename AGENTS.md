# Rose Empire project instructions

## Business
Rose Empire is a UK B2B wholesale bedding supplier focused on mattress protectors and pillows.

## Audience
Hotels, care homes, retailers, procurement teams, guest houses, distributors.

## Main goals
- Increase qualified quote requests
- Increase catalog downloads
- Improve mobile conversion
- Improve trust and clarity on product pages
- Support SEO landing pages for trade buyers

## Working style
- Always audit before editing
- Keep changes conversion-focused
- Prefer direct-response copy over vague branding copy
- Use plain, concise UK English
- Show exact files to edit before editing them
- Break large tasks into small tasks

## Metrics
Track:
- Quote button clicks
- Catalog downloads
- Form submissions
- Call clicks
- Conversion by traffic source
